## Scope notes

- **Package registration.** The Policy Deadlines row (2026-09-30) is addressed to Play apps generally and warns of global removal if not registered. The developer verification page scopes the first protections to installs from participating stores in four countries on Android 7+ certified devices, with global expansion in 2027. Both are shown. Treat registration as required now.
- **External content links.** The 2027-02-01 date applies to developers enrolled in the US external content links program, not to external links in general. Play Billing is not required in the US on mobile and tablet apps under the injunction, so a US link-out is a violation only when the Payments policy or program rules are not followed. Other regions differ.
- **16 KB.** Only apps targeting API 35+, with native code, on 64-bit devices. Java and Kotlin-only apps comply by default. Wear OS and Android TV already have their own dates above.
- **Japan.** The payment hold is global for sellers into or out of Japan if authorization is not completed.
- **Trader status.** Scope unverified; do not tell a user they are or are not a trader from this file.
- **Undated item.** Play Age Signals is launching for all developers globally per the 2026-10-29 reminder. No deadline was found.

## Conflict to flag

The Policy Deadlines page row for 2027-01-27 location says the location button is "recommended" as the minimum scope for precise location. The 2026-10-29 announcement describes the policy as becoming mandatory on 2027-01-27 and says that apps targeting API 37+ must use the location button for one-time or infrequent location requests. The permissions help page repeats "must". Resolve it on the live pages; until then report a missing location button for API 37+ apps as an upcoming requirement with a stated conflict.
